# Karst Fliesenleger: Website-Entwurf

Statischer Designentwurf für Oliver Karst, Fliesenleger in Neubrandenburg. Kein Build-Schritt:
`python3 -m http.server` im Ordner starten und `index.html` öffnen.
Vorschau: https://sibagatovmihail.github.io/karst-fliesenleger/
